O que são Formularios?

o que são formularios?

Os formularios são uma das partes mais importantes do nosso HTML semântico. Ele serve para

  • Entrada de dados
  • Interação
  • Acessibilidade
  • Validação e envio de informações

como trabalhar com um form no HTML

Para comerçarmos a Trabalhar com um formulário dentro do HTML, utilizamos o elemento de < form >

Esse elemento, representa um formulario interativo

utilizamos o atributo chamdo de target. Esse atributo serve para indicar onde o link configurado no href será aberto

Algumas opções do target:

  • _self: abre na mesma aba. É a configuração padrão.
  • _blank: abre o link em uma nova aba ou janela.
  • _parent: abre no contexto pai, usando iframe.
  • _top: abre no contexto mais externo tambem com iframe.
